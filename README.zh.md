# PizzaScan · 中文

## 2.3.23 · Build 58

PizzaScan 可在全球查找披萨店和意大利餐厅。普通地图和全屏地图加载相同的 POI；GPS 移动地图后会自动扫描可见区域。弹窗、到访、评论和地点详情共享同一个 0.1–10.0 的实时数值。

应用和 GitHub 语言页面会自动检测浏览器/设备语言。支持德语、英语、意大利语、西班牙语、法语、葡萄牙语、荷兰语、波兰语、土耳其语、俄语、日语、中文、韩语和阿拉伯语。菜单、下拉框、加载提示和状态消息也会跟随所选语言。
