# PizzaScan · English

## 2.3.23 · Build 58

PizzaScan finds pizza, pizzerias and Italian places worldwide. The map and fullscreen map load the same POIs; after GPS moves the map, the visible area is scanned automatically. Popup, personal visit, review and place detail share one live 0.1–10.0 value.

The app and GitHub language page detect browser/device language automatically. German, English, Italian, Spanish, French, Portuguese, Dutch, Polish, Turkish, Russian, Japanese, Chinese, Korean and Arabic are available. Menus, dropdowns, loading indicators and status messages follow the selected language too.
