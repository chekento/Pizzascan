# PizzaScan · Português

## 2.3.23 · Build 58

O PizzaScan encontra pizzas, pizzarias e locais italianos em todo o mundo. O mapa e o mapa em ecrã inteiro carregam os mesmos POI; depois de o GPS mover o mapa, a área visível é analisada automaticamente. Popup, visita, avaliação e detalhe usam o mesmo valor em direto de 0,1 a 10,0.

A aplicação e a página linguística do GitHub detetam automaticamente o idioma do navegador/dispositivo. Também estão disponíveis neerlandês, polaco, turco, russo, japonês, chinês, coreano e árabe, além de alemão, inglês, italiano, espanhol e francês. Menus, listas, carregamentos e estados acompanham o idioma escolhido.
