# PizzaScan · Русский

## 2.3.23 · Build 58

PizzaScan находит пиццу, пиццерии и итальянские заведения по всему миру. Карта и полноэкранная карта загружают одни и те же POI; после перемещения карты GPS автоматически сканирует видимую область. Всплывающее окно, визит, отзыв и карточка места используют одно живое значение от 0,1 до 10,0.

Приложение и языковая страница GitHub автоматически определяют язык браузера/устройства. Доступны немецкий, английский, итальянский, испанский, французский, португальский, нидерландский, польский, турецкий, русский, японский, китайский, корейский и арабский языки. Меню, списки, загрузка и статусы также следуют выбранному языку.
