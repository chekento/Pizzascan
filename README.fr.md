# PizzaScan · Français

## 2.3.23 · Build 58

PizzaScan trouve des pizzas, pizzerias et lieux italiens partout dans le monde. La carte et la carte plein écran chargent les mêmes POI ; après le déplacement GPS, la zone visible est analysée automatiquement. La popup, la visite, l’avis et le détail partagent la même valeur en direct de 0,1 à 10,0.

L’application et la page linguistique GitHub détectent automatiquement la langue du navigateur/de l’appareil. Allemand, anglais, italien, espagnol, français, portugais, néerlandais, polonais, turc, russe, japonais, chinois, coréen et arabe sont disponibles. Menus, listes déroulantes, chargements et états suivent aussi la langue choisie.
