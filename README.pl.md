# PizzaScan · Polski

## 2.3.23 · Build 58

PizzaScan znajduje pizzę, pizzerie i włoskie lokale na całym świecie. Mapa i mapa pełnoekranowa ładują te same POI; po przesunięciu mapy przez GPS automatycznie skanowany jest widoczny obszar. Popup, wizyta, recenzja i szczegóły miejsca korzystają z tej samej wartości na żywo od 0,1 do 10,0.

Aplikacja i strona językowa GitHub automatycznie wykrywają język przeglądarki/urządzenia. Dostępne są niemiecki, angielski, włoski, hiszpański, francuski, portugalski, niderlandzki, polski, turecki, rosyjski, japoński, chiński, koreański i arabski. Menu, listy, komunikaty ładowania i stany również używają wybranego języka.
