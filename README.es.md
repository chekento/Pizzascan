# PizzaScan · Español

## 2.3.23 · Build 58

PizzaScan encuentra pizza, pizzerías y lugares italianos en todo el mundo. El mapa y el mapa a pantalla completa cargan los mismos POI; después de mover el mapa con GPS se analiza automáticamente el área visible. El popup, la visita, la reseña y el detalle comparten el mismo valor en vivo de 0,1 a 10,0.

La app y la página lingüística de GitHub detectan automáticamente el idioma del navegador/dispositivo. Están disponibles alemán, inglés, italiano, español, francés, portugués, neerlandés, polaco, turco, ruso, japonés, chino, coreano y árabe. Menús, listas desplegables, cargas y estados siguen el idioma elegido.
