# PizzaScan · 한국어

## 2.3.23 · Build 58

PizzaScan은 전 세계의 피자집, 피자리아, 이탈리아 음식점을 찾습니다. 일반 지도와 전체 화면 지도는 같은 POI를 로드하며, GPS로 지도를 이동하면 보이는 영역을 자동으로 스캔합니다. 팝업, 방문, 리뷰, 장소 상세는 0.1~10.0의 동일한 실시간 값을 사용합니다.

앱과 GitHub 언어 페이지는 브라우저/기기 언어를 자동으로 감지합니다. 독일어, 영어, 이탈리아어, 스페인어, 프랑스어, 포르투갈어, 네덜란드어, 폴란드어, 터키어, 러시아어, 일본어, 중국어, 한국어, 아랍어를 제공합니다. 메뉴, 드롭다운, 로딩 및 상태 메시지도 선택한 언어를 따릅니다.
